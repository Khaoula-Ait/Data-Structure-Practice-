# Data Structures Practice in C#

A structured collection of data structure implementations and problem-solving exercises written in C#.
This repository documents my hands-on practice with core computer science concepts, focusing on clean, modular code,
memory management, and algorithmic efficiency.

## 🛠️ Tech Stack & Environment
* **Language:** C#
* **Framework:** .NET
* **IDE:** Visual Studio

## 📂 Repository Structure
The repository is organized by topic, starting with linear data structures:

* **`01-Lists/`** *(In Progress)*
  * Custom Singly & Doubly Linked List implementations from scratch
  * Operations and problem-solving using .NET's `List<T>`
  * Traversal, insertion, deletion, and reversal exercises
* **`02-Stacks-and-Queues/`** *(Planned)*
* **`03-Hash-Tables/`** *(Planned)*
* **`04-Trees-and-Graphs/`** *(Planned)*

## 🎯 Key Focus Areas
* **Under-the-Hood Implementation:** Building structures manually using nodes, references, and generics (`<T>`) rather than relying solely on `System.Collections.Generic`.
* **Complexity Analysis:** Documenting **Time and Space Complexity** (Big $O$) for key operations in code comments.
* **Clean Architecture:** Applying solid OOP principles and C# best practices.
